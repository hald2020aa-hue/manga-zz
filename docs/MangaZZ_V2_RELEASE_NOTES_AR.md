# Manga ZZ V2 — التحديث المبدئي

هذا الإصدار **كود مصدري جاهز لمحاولة تجميعه**، وليس APK مجرّبًا. يجب اجتياز GitHub Actions وتجربته على الهاتف قبل دمجه في `main`.

## ما تم وصله فعليًا

- إصلاح تجربة **إضافة المصادر**: حفظ واضح، تحقق من رابط HTTPS، منع التكرار، وإظهار أزرار فتح/تعديل/حذف.
- إمكانية حفظ قواعد CSS اختيارية لكل مصدر للوصول إلى صفحات HTML الثابتة **إذا كان المصدر يسمح بذلك**. لا يضمن تنزيل أو استخراج أي موقع عشوائي.
- ظهور زر **الحفظ في المكتبة** وزر **تنزيل الرابط** في واجهة WebView؛ زر التنزيل ينقل الرابط إلى مدير تنزيل الملفات المباشرة. رابط صفحة HTML ليس ملفًا مباشرًا، وقد يرفضه المصدر.
- مكتبة بشبكة متكيّفة مع الشاشات القابلة للطي، ومجلدات وفلاتر ومفضلة وتقدم قراءة.
- قارئ موجود مسبقًا بتكبير وتمرير عمودي/أفقي، وإضافة فتح صفحات محلية/مستخرجة. OCR والترجمة النصية المتوفرة سابقًا لا تستبدل فقاعات الصور.
- جلب/تنزيل فصول من مصادر HTML الثابتة فقط باستخدام قواعد CSS يحددها المستخدم، مع إصدار CBZ عند اكتمال تنزيل الصور.
- خمسة ثيمات ملونة تطبق على الخلفية والزجاج والحدود والأزرار؛ بعض عناصر Material ما زالت بحاجة إلى تحسينات بصرية.
- النسخ الاحتياطي: بيانات المكتبة وقواعد CSS والثيم والقراءة؛ **لا يشمل الصور المحملة ولا يضمن استعادة صلاحيات ملفات الهاتف**.
- رسوم Lottie المرفقة موجودة في حزمة الموارد؛ لا تدعي أن كل حركة مرتبطة بحدث.

## لم ينجز بعد

- ترجمة الفقاعات مباشرةً داخل صور المانجا.
- نظام تنزيل فصول مجدول بخلفية WorkManager مع استئناف لكل صورة.
- نسخ احتياطي مشفر يشمل الصور عبر الأجهزة.
- دعم مضمون لكل المواقع أو حماية التجاوز.
- قياسات 60FPS أو اختبارات أجهزة فعلية.

## الأمان

- لا تغييرات على قاعدة بيانات Room في هذا الإصدار.
- اقرأ سجل الأخطاء في GitHub Actions أولًا، ثم راجع نسخة APK الجديدة.
- **لا تدمج فرع V2 في main إلا بعد نجاح بناء Android واختبار الحفظ والمصادر والقراءة.**
- ملفات المرجع Tachiyomi مرخّصة ضمن الملف المرفق؛ تأكد من تراخيص المحتوى والمصادر.

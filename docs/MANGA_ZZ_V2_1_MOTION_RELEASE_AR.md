# Manga ZZ V2.1 — Motion & Theme Update

هذا تحديث تدريجي فوق فرع `feature/mangazz-v2-integration-20261023` من المستودع `hald2020aa-hue/manga-zz`، دون الكتابة على `main`.

## يشمل
- 7 أيقونات Vector Android جديدة، يتم تلوينها تلقائيًا بألوان الثيم الحالي.
- `MotionFeedback.kt`: إشعارات Lottie قصيرة تتلاشى بعد 1.65 ثانية بدل الحركة الدائمة.
- `MainActivity.kt`: أحداث نجاح/فشل المصادر والمفضلة والنسخ الاحتياطي والتنقل.
- `SourcesV2.kt`: حفظ قواعد CSS والحفظ داخل المصادر مع إشارات الفشل والنجاح؛ يحافظ على إصلاح `LocalContext.current` الموجود في V2.
- `LibraryV2.kt`: أيقونات إضافة عمل والمفضلة.
- `BrowserScreen.kt`: حركة أثناء تحميل صفحة ويب وعناصر حفظ/تنزيل مرئية أسفل المتصفح.
- `ReaderScreen.kt`: حركة تغير الصفحة واستجابة OCR/الترجمة.
- `ChaptersV2.kt`: حركة تقدم تنزيل الفصل وانتهاء تصدير CBZ.
- `ManagementScreens.kt`: حركة بدء واكتمال/فشل التنزيل وأزرار استيراد وتصدير النسخ الاحتياطية.
- استخدام ثيمات V2 في البطاقات والأزرار والعناوين، ودعم خمس لوحات ألوان.

## مهم
- موارد Lottie الـ37 الموجودة في فرع V2 تُعاد استخدامها ولا تُنسخ مرتين في رقعة التحديث.
- شاشة الترجمة الحالية تعرض النص العربي الناتج، ولا تستبدل النص داخل الفقاعات على الصورة.
- لا يُسمح بتنزيل المحتوى المحمي أو تجاوز سياسات المواقع.
- هذا أرشيف **كود مصدر** وليس APK. تم فحص الموارد والصيغ والأرشيف محليًا، لكن **Gradle assembleDebug لم يُنفّذ هنا**. يبدأ عند دفع الفرع إلى GitHub Actions.
- التطبيق يحتفظ بنفس `applicationId` وقاعدة بيانات Room (الإصدار 1)، ويزداد `versionCode` إلى 3 ليتناسب مع التحديث.

## خطوات تثبيت التحديث دون العبث بالنسخة الشغالة
1. نزّل `MangaZZ_V2_1_Motion_Update.zip` و`MangaZZ_V2_1_Termux_Upload.sh` إلى Download.
2. نفّذ السكربت من Termux (راجع الأمر في المحادثة).
3. يعمل السكربت على فرع جديد `feature/mangazz-v2-motion-20261023` مشتق من V2، ويرفعه.
4. راجع GitHub Actions ثم اختبر APK، وبعد التأكد افتح Pull Request؛ لا تدمج قبل نجاح الاختبار.
